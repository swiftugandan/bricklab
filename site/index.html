Bricklab
Source on GitHub Open the studio

Build with bricks, right in your browser.

Bricklab is a free 3D brick workshop. Snap pieces onto a 32 × 32 stud plate, stack and paint them, and pick up where you left off next time. Nothing to download and no account to make.

What's in the box

Pieces

19 pieces in four groups: bricks, plates, tiles, and special shapes like slopes and rounds.

Every piece snaps to the stud grid and turns in quarter steps. Gravity is on: pieces rest on what's below or hang from studs above, and anything left unsupported falls.

Tools

Build, select, move, paint, erase and rotate. Raise or lower a piece one plate at a time.

Undo and redo go back 80 steps, so trying an idea costs nothing.

Your builds

Your work saves itself on this device as you go. Export a .bricklab file to keep or share, then import it back any time.

Save a PNG snapshot, or start fresh from a blank plate, the Sunshine studio or the Colour tower.

Open source, with nothing to install

Bricklab is plain JavaScript and Three.js. There's no framework, no build step and no tracking. It draws with WebGPU where your browser supports it and falls back to WebGL 2 elsewhere.

To run your own copy, clone the repository and serve the studio folder:

git clone https://github.com/swiftugandan/bricklab.git
cd bricklab
python3 -m http.server 4173 --directory dist
